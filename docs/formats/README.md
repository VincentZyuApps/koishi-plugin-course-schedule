## 🧭 各方案选型建议

1. **教务系统有对应适配工具？**
   - 首选 **WakeUp 课程表（降级至 6.0.23）**，在 App 内自动从教务系统导入课表后，点击右上角分享课表，复制分享口令给 Bot 发送 `课表.绑定` 即可一键入库。
2. **教务系统没有适配工具，只能截图？**
   - 推荐使用 AI（如 Gemini、GPT-4o、Claude）识别课表截图，要求其输出符合 **[Yunzai 原生 JSON](./yunzai-schedule-plugin-json.md)** 格式的文本，直接粘贴给 Bot 完成绑定。
3. **正在使用星链课表 App？**
   - 可直接使用 **[星链分享码或导出 JSON](./starlink-schedule.md)**；导入后别忘了通过 `课表.设置星链时间表` 上传您学校的作息时间表，插件会自动为您刷新同步上课时间。
